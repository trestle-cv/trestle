# Trestle v0.1.6

Trestle v0.1.6 is a stable public-preview release.

- Establishes the replicated mutation-consequence contract for SQLite
  clustering: record create/update/delete replicates its event, audit fact and
  matched automation job obligations atomically, matching standalone
  behaviour.
- Makes webhook/function definitions consensus state with deterministic
  automation matching on every node.
- Makes the job lifecycle (claim, completion, retry, cancel, stale release)
  raft-mediated while external webhook/Lambda delivery stays asynchronous and
  at-least-once.
- Makes batch record creation one atomic replicated operation.
- Extends snapshots/restore to the full consensus surface (records, events,
  audit, jobs, automation definitions).
- Enforces cluster-uniform `webhook.key` compatibility at the replication
  handshake and at voter admission via a non-secret SHA-256 fingerprint.
- Enforces a clean consensus-owned state for first-time voters and an explicit
  Lambda leader-capability contract (durable pending obligations plus a
  leadership-transfer operator endpoint).
