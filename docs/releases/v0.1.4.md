# Trestle v0.1.4

Trestle v0.1.4 is a stable public-preview release.

- Adopts the canonical Gantry Core multi-account authorization model.
- Adds the shared-layout management console and aligns the embedded launcher
  with Trestle's public design.
- Adds headless setup and confirmation-protected `reset --auth` and
  `reset --all` commands.
- Corrects reset targeting when Trestle is run as an installed service.
- Pins Gantry Core v0.1.0 for reproducible standalone builds.
